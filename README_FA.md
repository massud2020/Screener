# Balanced Screener — نسخه اصلاح‌شده

## اضافه شدن استراتژی جدید
در منوی بالای اپلیکیشن اکنون گزینه سوم **Forex_Crypto_MTF_LongShort** اضافه شده است. این گزینه مستقل از دو استراتژی قبلی است.

### قوانین پیاده‌سازی‌شده
- تایم‌فریم ورود M5 و استفاده از کندل‌های بسته‌شده.
- LONG: ساختار EMA21 > EMA50 > EMA200 و الگوی ۳ کندل نزولی + یک کندل صعودی که کندل صعودی آخرین کندل بسته‌شده باشد.
- SHORT: ساختار EMA21 < EMA50 < EMA200 و الگوی ۳ کندل صعودی + یک کندل نزولی که کندل نزولی آخرین کندل بسته‌شده باشد.
- اندازه بدنه کندل مخالف حداقل ۵۰٪ مجموع بدنه سه کندل دیگر.
- امتیازدهی RSI، روند M15، روند سخت‌گیرانه H1، VWAP روزانه، شیب EMA و رژیم ATR؛ حداقل امتیاز پیش‌فرض ۵ از ۸.
- فیلتر ATR درصدی و فاصله EMAها نسبت به ATR.
- حد ضرر = ۱٫۵ × ATR(14)، حد سود = ۲٫۵ برابر ریسک.
- نمایش TP و امتیاز در فهرست و پنجره نمودار.

## اجرا
با Python 3 در پوشه پروژه اجرا کنید:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای نصب PWA روی موبایل، پروژه را روی هاست HTTPS منتشر کنید.

## محدودیت مهم
این نسخه از داده‌های کندلی APIها استفاده می‌کند. فیلتر اسپرد بروکر در فایل MQL5 اصلی به Bid/Ask لحظه‌ای و مشخصات point نماد وابسته است و از OHLC به‌تنهایی قابل محاسبه دقیق نیست؛ بنابراین این فیلتر در نسخه وب عیناً بازتولید نشده است. VWAP به حجم ارائه‌شده از سوی منبع داده نیاز دارد؛ اگر منبع برای نماد حجم ندهد، سیگنال این استراتژی تولید نمی‌شود. در نتیجه برای تطابق کامل با اجرای MQL5، باید منبع داده دارای Bid/Ask و حجم معتبر باشد.

این برنامه فقط تحلیل و هشدار ارائه می‌کند و سفارش معاملاتی ارسال نمی‌کند. پیش از استفاده واقعی، آن را روی داده تاریخی و حساب آزمایشی بررسی کنید.
