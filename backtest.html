۱ · داده‌ی MT5

برای هر نماد یک فایل CSV با تایم‌فریم M5 (یا M1) انتخاب کن. فایل‌ها روی همین گوشی ذخیره می‌شن و به جایی فرستاده نمی‌شن. ساعت‌ها همون ساعت سرور بروکر هستن؛ Daily Open هم با شروع روز سرور حساب می‌شه.

＋ انتخاب فایل‌های CSVچند فایل رو هم‌زمان می‌شه انتخاب کرد
راهنمای گرفتن خروجی از MT5

روش ۱ · از خود MT5 (دسکتاپ)

  1. توی MT5 کلید Ctrl+U یا منوی View ‹ Symbols رو بزن.
  2. تب Bars، نماد و تایم‌فریم M5 و بازه‌ی تاریخ رو انتخاب کن و Request بزن.
  3. دکمه‌ی Export Bars رو بزن و فایل CSV رو ذخیره کن.
  4. اگه تعداد کندل‌ها کم بود: Tools ‹ Options ‹ Charts و مقدار Max bars in chart رو روی Unlimited بذار، بعد MT5 رو ببند و باز کن.

روش ۲ · اسکریپت آماده

  1. فایل MT5_ExportBars.mq5 (داخل زیپ اپ) رو توی MQL5/Scripts بذار و توی MetaEditor کامپایل کن.
  2. روی چارت هر نماد بندازش، یا اسم چند نماد رو با کاما توی ورودی Symbols بنویس.
  3. فایل‌ها توی File ‹ Open Data Folder ‹ MQL5 ‹ Files ساخته می‌شن.

نکته‌ها

  • MT5 موبایل خروجی CSV نمی‌ده؛ از دسکتاپ استفاده کن و فایل‌ها رو به گوشی منتقل کن.
  • برای فیلتر H1 و استراتژی FVG حداقل حدود ۳٬۰۰۰ کندل M5 (حدود ۲ هفته) لازمه؛ برای نتیجه‌ی قابل‌اتکا ۶ ماه تا ۲ سال بهتره.
  • قالب‌های Tab، کاما و نقطه‌ویرگول و فایل‌های UTF-16 پشتیبانی می‌شن.
